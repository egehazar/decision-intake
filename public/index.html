        How it works

        The DecisionIntake engine learned from 48,657 households scored by PolicyEngine-US, an open model of the 2026 benefit rules. After each answer it asks the question most likely to change what you should apply for, and stops when another question isn't worth your time.

        How well it does

        In tests on 2,000 simulated households it had never seen, it asked 8 questions on average instead of 18 (the difference in mistakes from asking all 18 was not statistically distinguishable from zero), and it beat the strongest decision tree and the best fixed 8-question form we could build. It has been tested against PolicyEngine's rules, not yet with real applicants. This is a screening estimate, not a decision: only the program can tell you for sure.
